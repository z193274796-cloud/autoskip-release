# 开屏跳过 (AutoSkip)

安卓开屏广告自动跳过工具。基于系统自带的无障碍服务，免 root，安装包仅约 50 KB，零第三方依赖、无任何统计 SDK。

> 仅供个人与家庭设备使用，请勿二次分发或商用。

## 功能

- 检测到开屏广告时自动点击"跳过"按钮（成功时轻微振动提示）
- 规则在线更新：订阅本仓库的 `rules.json`，**无需任何令牌**（公开仓库，直接可读）
- app 自动更新：每 24 小时检查本仓库 `app/app.json`，发现新版本自动下载校验，手机上点一次"安装"即可，**同样无需令牌**
- 误点保护：只在窗口切换后 8 秒内工作、按包名免打扰、危险文案拒点

## 安装（约 1 分钟）

1. 下载 [`app/autoskip-v1.5.apk`](app/autoskip-v1.5.apk) 传到手机（数据线 / QQ / 网盘均可；微信会改后缀名为 `.apk.1`，重命名去掉 `.1` 再装），点击安装，允许"来自此来源的应用"
2. 打开"开屏跳过" → 点【去开启】→ 找到无障碍/辅助功能里"开屏跳过"打开开关，回到 app 看到绿色 ✓
3. 建议：点【电池优化白名单】允许，并按【保活设置教程】开自启动

## 规则订阅（可选，推荐）

在 app 的"规则订阅"卡片里：

- 订阅链接：`https://raw.githubusercontent.com/z193274796-cloud/autoskip-release/main/rules.json`
- 访问令牌：**留空即可**（公开仓库不需要）

之后每 24 小时自动更新规则；遇到跳不过的广告，用 app 里的【抓屏诊断】把剪贴板内容发给作者加规则。

## 隐私

- 联网仅用于下载规则文件和检查/下载 app 更新，全部指向本仓库，无统计、无其他上报
- 无障碍服务仅读取屏幕控件的文字并模拟点击，不记录、不上传
- 跳过记录只存在手机内存里
